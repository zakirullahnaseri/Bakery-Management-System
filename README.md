# 🥐 Bakery Management System

A professional web-based **Bakery Management System** designed to help manage bakery products, categories, customers, orders, prices, and inventory through a simple and responsive interface.

## 🚀 Features

* 🥖 Add, update, and delete bakery products
* 📦 Manage product inventory
* 🏷️ Manage product categories
* 💰 Manage product prices
* 🛒 Manage customer orders
* 👤 Manage customer information
* 🔍 Search and filter products
* 📱 Responsive and mobile-friendly design
* 💾 Database integration
* 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Custom styling and layout
* **Bootstrap** — Responsive UI and components
* **JavaScript** — Frontend interactions and dynamic functionality
* **PHP** — Backend logic and server-side processing
* **MySQL** — Database management

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Move the Project

If you are using **XAMPP**:

```text
C:\xampp\htdocs\bakery-management-system
```

If you are using **WAMP**:

```text
C:\wamp64\www\bakery-management-system
```

### 3. Start the Server

Start:

* Apache
* MySQL

from your XAMPP/WAMP control panel.

### 4. Create the Database

Open:

```text
http://localhost/phpmyadmin
```

Create a database, for example:

```text
bakery_management
```

Then import your project's SQL database file if available.

### 5. Configure Database Connection

Update your PHP database configuration with your MySQL credentials:

```php
$host = "localhost";
$username = "root";
$password = "";
$database = "bakery_management";
```

### 6. Run the Project

Open your browser and visit:

```text
http://localhost/bakery-management-system/
```
